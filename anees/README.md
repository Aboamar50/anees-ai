# أنيس — واجهة تجريبية

واجهة عربية RTL متجاوبة لتطبيق أنيس، بملف HTML واحد دون مكتبات خارجية.

## التشغيل محليًا
افتح `index.html` في المتصفح.

## التفاعل الموجود
- زر «ابدأ الآن» يفتح شاشة الجلسة.
- زر «كتم» يبدّل حالة الواجهة فقط؛ الصوت غير مفعّل.
- زر «إنهاء» يعيدك إلى شاشة الترحيب.

## النشر على Cloudflare Pages
ارفع مجلد المشروع أو مستودع Git الذي يحتوي على `index.html` إلى Cloudflare Pages.
هذه واجهة فقط ولا يوجد خادم خلفي أو تسجيل دخول أو تخزين بيانات.
